# 블록 도우미

8×8 블록 퍼즐 게임(블록 3개를 받아 가로·세로 줄을 지우는 방식)에서 최선의 수를 찾아주는 Android 앱이에요.
게임 화면을 읽어서 놓을 자리를 화면 위에 표시하거나, 블록을 대신 끌어다 놓아요.

- **추천 모드**: 놓을 순서(1→2→3)와 자리를 색 테두리로 게임 화면 위에 표시해요.
- **자동 모드**: 블록을 직접 끌어다 놓고, 줄이 지워지는 애니메이션이 끝나면 다음 수를 둬요.
- **진단**: 지금 화면과 인식 결과를 갤러리 `Pictures/BlockHelper`에 저장해요.

Android 11 이상이 필요해요. 갤럭시 탭 S10 FE(1440×2304) 게임 화면을 기준으로 맞췄고, 다른 해상도에서도 보드 위치를 자동으로 찾아요.

## 설치

1. `app-debug.apk`를 기기에 받아서 설치해요. 출처를 알 수 없는 앱 설치를 허용해야 해요.
2. 앱을 열고 **접근성 설정 열기**를 눌러 '블록 도우미'를 켜요.
   회색으로 막혀 있으면 **앱 정보 열기 → 오른쪽 위 ⋮ → 제한된 설정 허용**을 누른 뒤 다시 켜요.
3. 게임을 실행하면 화면 위에 패널이 떠요. 제목 줄(⠿)을 끌어서 보드에 겹치지 않는 위쪽에 두세요.

> 디버그 서명으로 빌드돼요. 다른 환경에서 새로 빌드한 APK는 서명이 달라서, 업데이트하려면 기존 앱을 지우고 설치해야 해요.

## 동작 방식

| 단계 | 파일 | 내용 |
| --- | --- | --- |
| 화면 캡처 | `BotService.kt` | 접근성 서비스의 `takeScreenshot` (Android 11+) |
| 인식 | `Recognizer.kt` | 배경색을 기준으로 정사각형 보드와 안쪽 격자를 찾고, 칸 중앙 색으로 채움 여부를 판단. 보드 아래를 3칸으로 나눠 트레이 블록 모양을 읽음 |
| 탐색 | `Solver.kt` | 블록 3개의 모든 순서와 위치(같은 결과는 합침)를 시도하고, 줄 클리어 점수 + 남은 보드 평가(빈칸 연결성, 구멍, 3×3·1×5 등이 들어갈 자리)로 고름 |
| 드래그 | `BotService.kt`, `DragProbe.kt` | 블록을 잡고 목표 근처에서 멈춘 채 스크린샷을 찍어, 끌고 있는 블록(또는 게임의 착지 미리보기) 위치를 찾아 손가락 위치를 보정한 뒤 놓음. 블록 크기별 보정값을 기억함 |
| 확인 | `BotService.kt` | 놓은 뒤 보드를 다시 읽어 예상과 비교하고, 어긋나면 보정값을 고침 |

평가 가중치는 무작위 블록 자가 대전으로 조정했어요. 블록을 균등하게 무작위로 받는 조건에서 평균 약 260턴을 버텨요(400턴 상한, 24판).

전략은 두 가지예요.

- **안정형**: 오래 버티는 쪽을 우선해요(기본).
- **콤보형**: 매번 줄을 지우는 쪽에 가산점을 줘요. 점수는 잘 오르지만 더 빨리 막힐 수 있어요.

## 빌드

```bash
./gradlew assembleDebug
```

```bash
./gradlew testDebugUnitTest
```

JDK 17 이상과 Android SDK(플랫폼 35)가 필요해요. `local.properties`에 `sdk.dir`을 적거나 `ANDROID_HOME`을 설정하세요.

테스트는 실제 게임 스크린샷(`app/src/test/resources`, 광고 영역은 지움)으로 보드·트레이 인식, 해상도 축소, L자 블록, 드래그 중 블록 찾기(착지 미리보기가 같이 보이는 경우 포함)를 확인하고, 탐색 엔진은 기준 구현과 40개 사례에서 점수가 일치하는지 확인해요.

## 알아두세요

- 자동 플레이는 게임 이용약관에 어긋날 수 있고, 계정 제재를 받을 수 있어요.
- 광고, 팝업, 게임 오버 화면에서는 보드를 읽지 못해서 자동 플레이가 멈춰요.
- 화면 내용은 기기 안에서만 처리하고 밖으로 보내지 않아요.
